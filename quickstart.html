Quickstart Guide

Go from an empty environment to a running, interactive AI agent in three steps.

1

Set your API key

Generate an API key in the Maritime dashboard settings under API keys, or run maritime keys create with the CLI. Then export the key in your shell:

bash 
export MARITIME_API_KEY="API_KEY"
Tip: Personal API keys start with mk_. For security, never commit this key to version control.
2

Create an agent

Create an agent from a ready-made template, such as openclaw:

bash 
curl -s -X POST https://api.maritime.sh/api/agents \
  -H "Authorization: Bearer $MARITIME_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"name": "my-first-agent", "templateId": "openclaw"}'
The API returns 201 Created with status: deploying. Copy the id value from the JSON response; the status changes to active in about 20 to 40 seconds.
3

Send a message

Send a chat prompt to your deployed agent. Replace AGENT_ID with the id returned in Step 2:

bash 
curl -s -X POST https://api.maritime.sh/api/agents/AGENT_ID/chat \
  -H "Authorization: Bearer $MARITIME_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"message": "Hello! Introduce yourself."}'
The call waits for the agent to reply, and returns 200 OK with {"response": "..."}. If the agent was asleep, the call wakes it automatically.
